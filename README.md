## Universidad Católica del Norte

### Introducción a la Inteligencia Artificial

Este repositorio consolida los proyectos, análisis de datos, modelos predictivos y documentación correspondientes a la asignatura **Introducción a la Inteligencia Artificial** de la **Universidad Católica del Norte**.

El objetivo de este repositorio es evidenciar el desarrollo práctico de los conocimientos adquiridos durante el curso, abarcando desde la programación lógica fundamental hasta la implementación de modelos de Machine Learning y el desarrollo de interfaces de usuario.

## 🔎 Descripción General

El repositorio está dividido en tres áreas principales de trabajo:

* **Documentación Académica:** Presentaciones y reportes formales sobre el Aprendizaje Basado en Proyectos (ABP).
* **Proyecto Calculadora:** Desarrollo de herramientas de cálculo, abarcando tanto interfaces de línea de comandos (CLI) con enfoque en lógica matemática, como interfaces gráficas de usuario (GUI).
* **Proyecto Principal (Machine Learning):** Implementación de análisis de datos y modelos predictivos, enfocado en casos de uso reales como la predicción de deserción estudiantil y la detección de anomalías.

## 📂 Estructura del Repositorio

A continuación, se detalla la organización técnica de los directorios y archivos:

* **`_Documentos/`** (Entregables teóricos y de presentación)
  * `Presentacion.pptx`: Material de apoyo visual para la defensa del proyecto.
  * `Taller-ABP.docx`: Documento formal con el planteamiento y desarrollo del Taller de Aprendizaje Basado en Proyectos.


* **`_Proyecto-Calculadora/`** (Fundamentos de programación lógica y visual)
  * **`Calculadora-CLI/`**
    *  `README.md`: Documentación específica de la versión de consola.
    *  `tabla-de-verdad.py`: Script en Python para la evaluación lógica y generación de tablas de verdad.
  * **`Calculadora-GUI/`**
    *    `README.md`: Documentación específica de la versión gráfica.
    *    `calculadora_gui.py`: Aplicación con Interfaz Gráfica de Usuario (GUI) funcional.
  * `README.md`: Guía general de la carpeta del proyecto de calculadoras.

* **`_Proyecto-Principal/`** (Núcleo de Inteligencia Artificial y Ciencia de Datos)
  * `Taller-ABP.ipynb`: Cuaderno de Jupyter (Notebook) con el análisis exploratorio de datos, entrenamiento y evaluación de modelos.
  * `app.py`: Script principal de la aplicación, posiblemente para el despliegue del modelo predictivo (ej. Flask, Streamlit).
  * `data.csv`: Conjunto de datos principal utilizado para el entrenamiento de los modelos.
  * `predict_students_dropout_and_...`: Archivo de datos o modelo exportado relacionado con la predicción de deserción académica.
  * `resultados_anomalias.csv`: Dataset generado con los resultados (output) del modelo de detección de anomalías.


* **Raíz del Repositorio**
  * `LICENSE`: Archivo de licencia del código fuente.
  * `README.md`: Este archivo principal de documentación.
